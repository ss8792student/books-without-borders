# Books Without Borders

The website for Books Without Borders, a youth-led 501(c)(3) nonprofit that makes free children's books in languages that have very few.

The whole site is `index.html` plus the images in `img/`. There is no build step. Open `index.html` in a browser to preview it.

To update the pilot shelf on the home page, edit the `BOOKS` list near the top of the script in `index.html`.

Contact: info@bwbglobal.org
